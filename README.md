# Plant the Future — Campaign Website

**Educational use only — school project**

This repository is a **classroom / academic project** for a PR campaign proposal (**Blueseeds × RE-THINK**: *Plant the Future: Return Beauty to Nature*). It is **not intended for public release or commercial use online**. Do not deploy or publish this site as an official brand or NGO property without permission from the rights holders.

## Disclaimer

- Fictional or proposal-level campaign content for coursework
- Brand names and concepts are used for **learning and presentation purposes only**
- Images, copy, and forms are placeholders unless otherwise noted by your instructor

## Run locally (preview)

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

Then visit the URL shown in the terminal (e.g. `http://localhost:3000`).

## Pages

| File | Purpose |
|------|---------|
| `index.html` | **Entry point** — fullscreen intro video (`images/video.mp4`) + Enter site |
| `hero.html` | Full campaign site — hero panel, highlights, team, join form |

## Project contents

- Hero and campaign overview (June 8 – July 8, 2026)
- Issue framing: plastic waste from personal care in Taiwan
- Campaign pillars and three key actions
- Campaign highlights, event spotlight, and event details
- Team section and join signup (demo form)

## Assets

Place images in the `images/` folder (e.g. `logo.png`, `video.mp4`, team photos, campaign graphics) as referenced in the HTML files
